# goal.md 양식

승인 후 불변. Claude가 고치지 못한다.

## 양식

```markdown
# 골 계약서

목표      <한 문장>
시작 시각  <date +%s 결과>

완료 판정
  □ <판정 가능한 항목>
  □ <판정 가능한 항목>

종료 조건  위 전항목 Y or <시간>

하지 말 것
  - <금지 항목>
```

## 종료 조건의 시간은 비워 두지 않는다

`종료 조건`의 `<시간>`은 **Claude가 반드시 채운다.** 사용자가 시간을 말하지 않았어도
비워 두거나 "전항목 Y"만 적지 않는다 — **기본값 `2시간`을 박는다.**

```
종료 조건  위 전항목 Y or 2시간      ← 사용자가 시간을 말하지 않아도 이렇게 쓴다
```

시간은 취향 칸이고, 취향은 묻지 않고 초안에 박는 것이 이 스킬의 규칙이다. 사용자는 승인
시점에 바꾸면 된다(`"3시간"`, `"30분"`). **시간이 비어 있으면 완료 판정이 서지 않는 런은
끝나는 조건을 하나도 갖지 못한다.**

## 완료 판정을 쓰는 법

**Claude가 초안을 쓰고 사용자가 고친다.** `"완료 판정을 뭐로 할까요?"`라고 묻지 않는다 —
사용자는 기준을 말로 내놓지 못한다. 초안에 반응하게 한다.

항목은 **작업이 끝났을 때 Y/N로 답할 수 있어야** 한다.

```
❌  □ 보고서를 충실하게 작성한다          ← 판정 불가
❌  □ 경쟁사를 충분히 조사한다            ← "충분히"가 판정 불가
✅  □ 5곳 × (플랜명·가격·과금단위) 표
✅  □ 우리 적용 시사점 3개
```

## 하지 말 것은 Claude가 채운다

사용자는 이 항목을 말하지 않는다. 추론해서 초안에 넣고 사용자가 더한다.
**자율주행 사고의 절반은 "안 시킨 걸 한 것"이다.**

기본 후보 — 작업 성격에 맞는 것만 고른다.
- 기존 파일·문서 구조 변경
- 외부 서비스 가입·결제
- 유료 데이터 구매
- 지정 범위 밖 파일 수정
- 커밋·푸시 (명시 없으면 금지)

## 골 디깅 대화 — 좋은 예

```
사용자: "경쟁사 가격정책 조사해서 보고서. 2시간."

Claude:
# 골 계약서
목표      경쟁사 가격정책 비교 보고서
완료 판정  □ 5곳 × 플랜·가격·과금단위 표
          □ 우리 적용 시사점 3개
종료 조건  위 전항목 Y or 2시간
하지 말 것 기존 문서 구조 변경 / 외부 서비스 가입 / 유료 데이터 구매

막힌 사실 하나: 경쟁사를 제가 고를까요, 지정하실까요?

사용자: "니가 골라. ㄱㄱ"
→ 출발. 이후 컨펌 없음.
```

## 나쁜 예

```
Claude: 몇 가지 확인하겠습니다.
1. 어떤 업종 경쟁사인가요?
2. 보고서 형식은 어떤 걸 원하세요?
3. 깊이는 어느 정도로?
4. 참고할 기존 자료가 있나요?
```

질문 4개는 스킬이 없을 때의 행동이다. 2·3번은 취향 질문이라 답이 안 나온다 —
초안에 박고 반응받는다. 사실 질문은 막힌 것만, 최대 2개.
