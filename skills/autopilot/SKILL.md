# autopilot

## Overview

혼자 달리면 완료 판정도 혼자 한다. **그게 자율주행의 유일한 치명적 위험이다.**

골 오해와 가정 누적은 파일로 잡힌다. "다 했다"는 믿음은 자기 자신이 못 잡는다.
그래서 바깥눈이 있다.

## 3단 구조

```
1단  골 디깅        ← 사용자가 개입하는 유일한 구간
       상한: 질의 2라운드, 사실 질문 최대 2개
       산출물: goal.md
       게이트: 승인하면 출발

2단  자율주행       ← 컨펌 없음
       goal.md만 보고 달린다
       말 안 한 결정은 assumptions.md에 적고 진행 — 멈추지 않는다

3단  종료·보고
       완료 판정 전항목 Y or 시간 만료
```

## 1단 — 골 디깅

양식과 작성법: `goal-template.md`

1. `.autopilot/<run-id>/` 를 만든다. `run-id` = `date +%Y%m%d-%H%M%S`
2. `goal.md` 초안을 쓴다. 완료 판정은 **작업이 끝났을 때 Y/N로 답할 수 있는 문장**으로.
3. 막힌 **사실**만 묻는다. 최대 2개. 취향은 묻지 않고 초안에 박는다.
4. 사용자 승인(`ㄱㄱ` 포함)을 받으면 `시작 시각`에 `date +%s`를 박고 출발한다.

**상한 2라운드.** 2라운드에 완료 판정이 서지 않으면 초안으로 출발한다 —
체크포인트 1에서 바깥눈이 잡는다. 골 디깅이 길면 자율주행의 의미가 없다.

**라운드 세는 법** — 라운드 하나는 `내 질문 1회 + 사용자 응답 1회`다. 사용자가 답하지
않거나 다른 화제로 넘어가면 그 라운드는 끝나지 않았고, 승인도 아니다 — 출발하지 않는다.

상한은 **완료 판정을 다듬는 데만** 적용된다. 2라운드를 소진하면 초안을 최종으로 제시하되
승인 게이트는 그대로다 — 승인 없이 출발하는 경로는 없다.

**승인 후 `goal.md`는 불변이다.**

## 2단 — 자율주행

`goal.md`만 보고 달린다. 컨펌을 요청하지 않는다.

**말 안 한 결정은 `assumptions.md`에 한 줄로 적고 진행한다. 멈추지 않는다.**

```
- 경쟁사 5곳을 국내 SaaS로 한정 (골에 범위 없음)
- 가격은 2026년 10월 공개가 기준
```

### 체크포인트 — 관측 가능한 트리거

시간 간격이 아니라 **되돌리기 비용이 급증하는 직전**이다.

| CP | 트리거 | 틀렸을 때 버려지는 것 |
|---|---|---|
| 1 | `goal.md` 승인 직후, **첫 작업물이 나오기 전** | 그 뒤 전부 |
| 2 | **산출물 파일이 처음 생성·저장되는 순간** | 재배치 비용 |
| 3 | 완료 판정 전항목을 Y로 적으려는 순간 | 투입 시간 전부 |
| 4 | `assumptions.md` 줄 수가 5를 넘을 때 | 전제가 뒤바뀌었을 수 있음 |

**트리거가 "그 순간"이 아니라 파일 상태·작업 단계인 것이 핵심이다.** "해석이
확정되는 순간"은 스스로 인지하지 못한 채 조용히 지나간다. 네 개 모두 외부에서 판별된다.

호출 방법은 `outside-eye.md`.

### 사고는 궤도 이탈뿐이다

| 상황 | 판정 |
|---|---|
| 못 한 것이 남아 있다 | 진척 부족. **사고 아님.** 기록만 |
| 다른 방향으로 가고 있다 | **사고** |

진척 부족은 사고가 아니다. 어려운 항목은 **같은 이유로 두 번 걸리고도 전진한다.**
기준은 "같은 이유냐"가 아니라 "방향이 바뀌었냐"다.

### 판정별 처리

| 판정 | 처리 |
|---|---|
| 수렴 | 계속 달린다 |
| 정체 | 계속 달린다. 2회 연속이면 **수단을 바꾼다** — 경로·도구·자료원 교체. 이탈 카운터는 리셋하지 않는다 |
| **이탈 1회** | `checkpoints.md` 마지막 `상태`로 **되돌리고** 다른 경로로 간다. 이탈 카운터 +1 |
| **이탈 2회 연속** | 골 해석이 틀린 것. **멈추고 사용자를 부른다** |
| 판단불가 | `outside-eye.md`의 판단불가 처리 |

수렴이나 정체가 한 번 나오면 **이탈 카운터는 0으로 리셋된다.** "2회 연속"이다.

### 멈추는 조건은 하나뿐이다

> **이탈 2회 연속.**

그 외에는 시간 만료까지 달린다. 못 한 것은 종료 보고에 올린다.

## Red Flags — 보이면 STOP

★ 표시는 서브에이전트 압박 테스트에서 **실제로 관측된** 합리화다. 나머지는 설계 검토에서 나온 것.

| 합리화 | 진실 |
|---|---|
| "이건 큰 결정이라 한 번 물어보자" | 승인은 `goal.md` 한 번뿐이다. 가정에 적고 가라 |
| ★ "골에 없지만 당연히 필요한 거니까 하자" | `하지 말 것`에 없어도 완료 판정에 없으면 그건 이탈이다 |
| "완료 판정 항목을 좀 더 좋게 다시 쓰자" | `goal.md`는 불변이다. 고쳐야 하면 멈춤 신호다 |
| "진척이 없으니 사고다" | 진척 부족은 사고가 아니다. 방향만 본다 |
| "같은 지적을 또 받았으니 멈추자" | 같은 이유로 두 번 걸려도 전진 중이면 계속이다 |
| "바깥눈이 이게 더 낫다니까 그렇게 하자" | `goal.md`에 없으면 기각이다. 바깥눈은 참고인이다 |
| "goal.md가 길어서 요약해서 보내자" | 요약하면 바깥눈이 다른 골로 판정한다. 전문이다 |
| "바깥눈이 판정을 못 했으니 다시 물어보자" | 1회만. 또 불가면 통과로 보고 간다 |
| "체크포인트 걸 타이밍이 애매하니 나중에" | 트리거는 파일 상태다. 애매하지 않다 |
| ★ "거의 다 했으니 CP3은 건너뛰자" | CP3이 완료 착각을 막는 유일한 지점이다 |
| "자리 비울 거라고는 했지만 이 정도는 확인하고 가는 게 맞겠다" | `알아서 끝내`가 이미 승인이다. 멈추면 그 지시를 어긴 것 — 가정에 적고 간다 |
| ★ "과금단위는 공개 정보가 없으니 일단 월 가격으로 정리해서 완료로 보고하자" | `가격정책`이 `월 가격`으로 줄어든 걸 적지 않으면 숨긴 이탈이다. 축소는 `assumptions.md`에 적고 종료 보고에도 올린다 |
